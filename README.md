# 대한민국 상권 분석 앱

공공데이터(소상공인시장진흥공단 상가(상권)정보) + Groq LLM 브리핑 + 카카오 지도로 만든
지역·업종별 상권 분석 대시보드. 서버 없이 정적 호스팅만으로 동작합니다.

## 기능

| 탭 | 내용 |
| --- | --- |
| 상권 분석 | 시/도→시/군/구→행정동, 업종 대→중→소 다단계 필터. 점포 수·점유율·시도 내 순위, **경쟁 강도 지수**, **공백(블루오션)/포화 업종**, 상위 업종·행정동 분포 |
| AI 상권 브리핑 | 계산된 통계를 프롬프트로 넣어 Groq LLM(Llama 3.3 70B 등)이 경쟁 강도 브리핑 + 차별화 전략 + 창업 팁 생성. 이어서 멀티턴 Q&A |
| 지도 | 카카오맵 마커 클러스터러로 점포 위치 시각화, 마커 클릭 시 상호·업종·주소 |
| 지역 비교 | 두 지역을 같은 업종 기준으로 나란히 비교 + CSV 내려받기 |
| 점포 목록 | 검색·페이징 + 필터 결과 CSV 내려받기 (엑셀 한글 깨짐 방지 BOM 포함) |

**경쟁 강도 지수** = (이 지역의 해당 업종 점유율) ÷ (같은 시/도 시군구 평균 점유율).
1.00이 평균, 1.5 이상이면 과열, 0.5 미만이면 공백 상권으로 판정합니다.

**공백 업종**은 시/도 평균 비중을 이 지역 점포 수에 적용한 *기대 점포 수*보다
실제 점포가 적은 업종입니다. 지역 규모 차이를 보정하기 때문에 큰 도시와 군 단위를 같이 비교해도 왜곡이 적습니다.

## 실행

```bash
npm install
npm run data:sample   # 샘플 데이터 생성 (public/data)
npm run dev
```

`http://localhost:5173` 접속 → 우측 상단 **API 키** 버튼에서 Groq / 카카오 키 입력.

Groq 키는 [console.groq.com/keys](https://console.groq.com/keys) 에서 무료로 발급받습니다(`gsk_` 로 시작).

## 데이터 채우기

샘플 데이터는 실제와 같은 스키마의 더미입니다. 실제 데이터로 바꾸는 방법은 두 가지입니다.

### 방법 A. 오픈 API (키 발급받은 경우) — 권장

1. `.env` 파일을 열고 발급받은 인증키를 넣습니다.

   ```
   DATA_GO_KR_KEY=여기에_일반_인증키(Decoding)
   ```

   data.go.kr → 마이페이지 → 오픈API → 인증키 발급현황의 **일반 인증키(Decoding)** 값입니다.
   (`%2B` 가 섞인 Encoding 키를 넣어도 스크립트가 자동으로 디코딩합니다.)

2. 원하는 지역 코드로 수집합니다.

   ```bash
   npm run data:api 41          # 경기도 전체
   npm run data:api 41820 41830 # 가평군·양평군만
   npm run data:api 11 41 51    # 서울 + 경기 + 강원
   ```

   시도 코드: `11` 서울 · `26` 부산 · `27` 대구 · `28` 인천 · `29` 광주 · `30` 대전 · `31` 울산 ·
   `36` 세종 · `41` 경기 · `43` 충북 · `44` 충남 · `46` 전남 · `47` 경북 · `48` 경남 ·
   `50` 제주 · `51` 강원 · `52` 전북

   - 완료된 지역은 다시 실행해도 재다운로드하지 않습니다. 새로 받으려면 `.cache/api/<코드>` 를 지우세요.
   - 기본 6개씩 동시 요청합니다. 조절하려면 `-- --concurrency=3`.
   - 페이지마다 `.cache/api/<코드>/p0001.json` 으로 저장되어, 끊겨도 같은 명령으로 이어받습니다.
   - 캐시만으로 `public/data` 를 다시 만들려면 `npm run data:api -- --build`.
   - 연결이 안 되면 `npm run data:api -- --check` 로 네트워크·키를 순서대로 진단합니다.
     사내망에서 HTTPS 가 막히면 명령 끝에 `-- --http` 를 붙이세요.
   - 1,000건씩 나눠 받으므로 시도 하나에 수백 번의 호출이 일어납니다. 개발계정 일일 트래픽(기본 10,000건)을 확인하세요.

   > API 키는 이 스크립트(로컬 Node)에서만 씁니다. 브라우저에서 직접 부르지 않는 이유는
   > data.go.kr이 CORS를 허용하지 않고, 키가 배포본에 노출되면 트래픽이 바로 소진되기 때문입니다.

### 방법 B. CSV 직접 다운로드

1. [공공데이터포털](https://www.data.go.kr)에서 *소상공인시장진흥공단 상가(상권)정보* 검색 → 시도별 CSV 다운로드
2. 한 폴더에 모아두고:

   ```bash
   npm run data:csv -- ./다운로드폴더
   ```

UTF-8·CP949 인코딩을 자동 판별하고, 필요한 9개 컬럼만 남겨 시군구 단위로 분할합니다.

### 생성 결과

```
public/data/
  index.json            지역·업종 목록 (앱 시작 시 1회 로드, 수십 KB)
  stores/s001-g001.json 시군구별 점포 (선택할 때만 로드, 사전 인코딩으로 경량화)
  summary/s001.json     시도별·시군구별 업종 집계 (평균/비교용)
```

전국 원본은 수백 MB라 브라우저가 통째로 받을 수 없어, **선택한 시군구 파일만 내려받는 구조**입니다.

수집을 실행할 때마다 `public/data` 는 **캐시에 있는 지역 전부로 다시 만들어집니다**.
경쟁 강도·공백 업종은 같은 시/도 안의 다른 시군구와 비교해 계산하므로,
시군구 한두 곳만 받으면 평균값이 왜곡됩니다. **시/도 단위(예: `41`)로 받는 것을 권장**합니다.

## 배포 (Netlify / Vercel / GitHub Pages)

```bash
npm run build   # dist/ 생성 (public/data 가 그대로 포함됩니다)
```

- Netlify: 빌드 명령 `npm run build`, 게시 디렉터리 `dist`
- GitHub Pages 등 하위 경로에 올릴 때는 `vite.config.js` 에 `base: '/저장소이름/'` 추가
- 카카오맵: Kakao Developers → 내 애플리케이션 → 플랫폼 → Web 에 배포 도메인 등록 필수

## 키 보관 정책

| 키 | 저장 위치 | 노출 |
| --- | --- | --- |
| 공공데이터포털 인증키 | `.env` (git 제외) | 로컬 수집 스크립트에서만 사용 |
| Groq API 키 | 브라우저 `localStorage` | 사용자 본인 브라우저에만 저장, 별도 서버 전송 없음 |
| 카카오 JavaScript 키 | 브라우저 `localStorage` | 도메인 등록으로 제한되는 공개형 키 |

공용 PC에서는 설정 모달의 **저장된 키 삭제**로 지우세요.
